# rocky-stats has moved

This repository is no longer maintained here. Development has moved to:

**https://git.tiuxo.com/brian/rocky-stats**

The code in this repository is archived at the state it had in June 2026 and
is missing several months of fixes, including support for newer Enterprise
Linux releases. Please use the new location for the current source.

Generated charts remain available at https://rocky-stats.tiuxo.com

## About

A data visualization project analyzing Enterprise Linux distribution usage
patterns using EPEL telemetry, comparing Rocky Linux, RHEL, CentOS variants,
AlmaLinux, and Oracle Linux usage trends over time.
